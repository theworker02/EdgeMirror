# Compatibility dates

```bash
edgemirror compat --dates 2024-11-11,2025-04-01
```

After `agent/cloudflare` merge, `edgemirror matrix` is an alias.

Cells are written only after **real local** executions. Remote matrix cells are never fabricated.

Filter default corpus slice with `--filter` (default often `http-get-root` for focused runs).
